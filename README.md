# Мессенджер (клиент-сервер)

Курсовой проект по дисциплине «Операционные системы»

## Возможности

- Личные сообщения между пользователями
- Групповые чаты с паролями
- Ответы на сообщения, пересылка, треды (ветки диалога)
- Регистрация новых пользователей
- История сообщений (SQLite)
- Офлайн-сообщения (доставка при входе)
- Шифрование AES-128 (OpenSSL)
- Многопоточный сервер (pthread) и клиент
- Хеш-таблица для быстрого поиска клиентов
- Обработчики сигналов (SIGINT, SIGTERM, SIGHUP)
- Логирование всех событий

## Платформы

| Платформа | Клиент                                   | Язык   |
|-----------|------------------------------------------|--------|
| Linux     | Консольный + псевдографический (ncurses) | C      |
| Windows   | Консольный с шифрованием                 | C      |
| Android   | Консольный (Termux)                      | Python |

## Сборка и запуск (Linux)

# Перейти в папку проекта
cd /mnt/hgfs/Messendger

# Собрать проект
make

# Запустить сервер
./bin/server

# Запустить консольный клиент
./bin/client

# Запустить псевдографический клиент (ncurses)
./bin/nclient


# Сборка Windows-клиента
cl win_client.c ws2_32.lib libcrypto.lib /Fe:win_client.exe
win_client.exe <IP_сервера>

# Запуск Android-клиента
pkg install python
pip install pycryptodome
python android_client.py <IP_сервера>
